# EMR 개발 현황 — 2026-09-13

전체 제품 완성 또는 운영 배포 완료를 의미하지 않습니다. 코드 구현, 자동 검증, 외부 서비스 연결을 구분합니다.

## 이번 변경

- 홈페이지 헤더·푸터와 EMR 워크스페이스에 공유 SVG 로고 적용. 블루·화이트 색상, 메뉴 계층, 업무별 홈페이지 미리보기 재설계.
- 대시보드와 대기실의 고정 환자·통계를 실제 예약 및 진료 API 조회로 교체.
- 대기실 자동 갱신, 환자 검색, 도착 확인, 진료 시작, 완료 처리, 이름 마스킹 전용 화면 구현.
- 예약 생성 시 직접 입력한 신규 환자도 같은 DB 트랜잭션에서 생성. 기존 환자 선택은 소유권 검사 후 연결.
- 예약 입력 검증, 시간 충돌 검사 직렬화, 상태 전이 제한, 중복 체크인 시 도착 시각 보존.
- 예약·차트·처방·수납·문진에서 존재하지 않는 사용자 name 속성을 참조하던 오류를 실제 full_name 필드로 수정.
- 한국 날짜 기준 조회 및 시간대가 포함된 입력의 정규화. 기존 timezone 없는 예약 컬럼은 한국 현지 시각으로 취급.
- 환자 목록의 가짜 데이터 폴백 제거. 없는 상세 ID는 404. 목록과 상세 응답 필드 통일.
- 환자 퍼널·동의 통계를 저장된 환자 데이터로 집계.
- 리포트 API 연결, 기간 선택, CSV 다운로드, 인쇄. 방문 없는 달의 수납액도 누락하지 않도록 월별 버킷 생성.
- 의원 설정의 저장·재조회와 사이드바 이름 반영. 고정 직원 목록은 기존 직원 ID 관리 화면으로 통합.
- 메뉴 팔레트에 실제 환자 검색 연결. 모바일 검색, 키보드 선택 순서, 상단 알림·설정 연결.
- 알림 목록·읽음·모두 읽음·삭제·페이지 이동을 실제 API에 연결.
- 도움말 검색과 접을 수 있는 사용 안내, 실제 문의 경로 연결. 문의 폼은 동일 출처 API 프록시 사용.
- 세션 확인 및 연결 실패 복구 화면, API 타임아웃 추가.
- 실제 로그인·회원가입 API 연결. 신규 의원 계정의 무료 STARTER 활성화, 비밀번호 복구 경로, 로그아웃과 계정 전환 시 캐시 초기화.
- 브라우저의 마이크·카메라 정책 차단 해제. 장치 사용에는 사용자의 브라우저 권한 허용이 필요.
- 누락된 PDF/이미지 의존성을 package-lock.json에 반영.

## 검증

- 예약 상태·입력·한국 날짜 경계 단위 테스트 10개 통과.
- Python 변경 모듈 문법 검사 통과.
- TypeScript 검사 통과 (최종 검증 결과는 작업 응답 참조).
- 브라우저 회귀 테스트: `frontend/e2e/emr-workspace.spec.ts`. API 응답을 모의하므로 실제 PostgreSQL 저장 검증을 대신하지 않음.
- 테스트 실행: `node node_modules/@playwright/test/cli.js test --config=playwright.workspace.config.ts`.
- 테스트 서버는 3117 포트와 `.next-e2e` 폴더를 사용.

## 남은 구현·검증

- 비대면 진료의 실제 통화 세션·장치·연결 실패 처리.
- 다중 지점 전환과 clinic_id 기준 전체 쿼리 전환. 기존 핵심 API는 user_id 소유권 기준을 유지.
- 직원 역할별 권한 집행. 직원 ID 정보 관리와 실제 접근 권한은 별개.

- 연동 설정, 약국 업무의 재고·처방·조제 상태 및 외부 연동 종단 검증.
- 보험청구 EDI·홈택스·알림톡·음성 서비스의 운영 자격증명, 계약 및 실제 응답 검증.
- 비용·리뷰·경영컨설팅 등 나머지 샘플 기반 화면의 전체 API 전환.
- 전체 홈페이지 하위 서비스, 약국 워크스페이스, 별도 portal 앱의 완전한 기능 감사 및 디자인 적용.
- 실제 PostgreSQL에 대한 환자 등록 → 예약 → 진료 → 처방 → 청구서 → 수납 통합 테스트.

## 데이터 관련 주의

기존 예약 데이터 중 이미 UTC를 timezone 없이 저장한 행이 있다면 자동으로 9시간 이동하지 않습니다. 기존 데이터의 저장 규칙을 확인한 뒤 별도 이관해야 합니다. 현재 코드는 새 입력의 시간대를 정규화합니다.

운영 배포·외부 시스템 전송은 이번 작업에서 실행하지 않았습니다.
